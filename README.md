# HabitFlow
🎓 О проекте
HabitFlow — клиентское веб-приложение для формирования полезных привычек, ежедневного отслеживания их выполнения и визуализации прогресса.
Приложение позволяет создавать собственные привычки, отмечать выполненные действия, следить за сериями последовательных дней (streaks) и отслеживать личные достижения.

🎯 Цель проекта
Разработать простой и удобный инструмент, который помогает пользователям поддерживать регулярность выполнения полезных привычек и отслеживать свой прогресс.

❗Важные моменты:
HabitFlow разрабатывается в рамках учебной проектной деятельности.
Тип проекта: веб-приложение
Предметная область: продуктивность и формирование привычек
Основная аудитория: пользователи, стремящиеся сформировать полезные привычки и отслеживать личный прогресс.
